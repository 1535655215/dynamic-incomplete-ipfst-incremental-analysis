# Publication checklist

Before citing this repository as public supplementary material:

1. Confirm authorship, affiliations and code ownership.
2. Review the MIT and CC BY 4.0 notices with all contributors.
3. Do not add third-party table transcriptions or copyrighted PDFs.
4. Create a tagged GitHub Release and record its URL and commit SHA.
5. Optionally enable Zenodo for a DOI.
6. Update the manuscript only after the release is publicly accessible.
